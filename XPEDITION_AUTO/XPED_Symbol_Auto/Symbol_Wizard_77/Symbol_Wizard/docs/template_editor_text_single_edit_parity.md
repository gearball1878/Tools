# Template Editor text single-edit parity

The Template Editor single-selection property panel for text items now uses the
same editable controls as the Symbol Wizard text panel:

- text content for plain text
- read-only generated content for attribute text
- font family
- bold / italic / underline
- size grid
- horizontal and vertical grid anchors
- wrap text for attributes or line-break hint for plain text
- rotation
- color

This fixes the historical reduced Template Editor text panel that only exposed
text, size and rotation through a compatibility refresh path.
